# FaceAge ClientScan

Система оценки возраста по лицу и проверки изображения на спуф (фото/экран) с использованием ONNX-модели.

## Используемая модель

[TrungTran/faceage_ClientScan](https://huggingface.co/TrungTran/faceage_ClientScan/tree/main)

---

## Запуск

### 1. Подготовка модели

1. Зарегистрируйтесь на [Hugging Face](https://huggingface.co/TrungTran/faceage_ClientScan/tree/main)
2. Скачайте файл модели **`faceage_dino_fp32.onnx`**
3. Разместите его в корневой директории проекта - рядом с `main.py`

### 2. Запуск сервера

В директории проекта выполните в консоли:

```bash
python -m uvicorn main:app --reload
```

### 3. Открытие интерфейса

Перейдите в браузере по адресу:

```
http://127.0.0.1:8000/
```

---

## Использование

1. **Разрешите** странице доступ к веб-камере
2. **Разместите лицо** в окне кадра
3. **Нажмите кнопку** «Сделать снимок»

---

## Логика проверки на спуф

Система анализирует снимок на наличие признаков **фотографии с экрана** - бликов, искажений и других характерных артефактов пересъёмки. При обнаружении подобных свойств изображение классифицируется как **спуф**.

---

## Результаты обработки

### Вариант А - Изображение подлинное

Отображается:

- Результат проверки на спуф
- **Примерный возраст** (погрешность по результатам испытаний - **менее 4 лет**)
- **Live Score** - коэффициент «живости» изображения

### Вариант Б - Обнаружен спуф

Отображается сообщение:

> **«Спуф (фото/экран)»**
